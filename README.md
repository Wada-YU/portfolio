# Yu Wada Portfolio — GitHub Pages 用ファイル

## 公開方法

1. GitHub の `portfolio` リポジトリを開く（なければ Public で作成）。
2. この ZIP を**展開**する。
3. `index.html`、`assignment04.ipynb`、`assets` フォルダを、**フォルダ構成を維持したまま**リポジトリの一番上にアップロードする。ZIP 自体をアップロードするのではない。
4. リポジトリの `Settings` → `Pages` → `Build and deployment` で `Deploy from a branch` を選び、`main`、`/(root)` を指定して Save。
5. 公開URL（例：`https://ユーザー名.github.io/portfolio/`）を開いて動作確認してから提出。

## 高専祭の画像について（差し替え済み）

送っていただいた「KosenNIGHT」の実際のゲーム画面4枚を `assets/festival-01.webp` ～ `assets/festival-04.webp` に追加済みです。`index.html` 内の画像説明と代替テキストも更新済みなので、そのまま公開できます。

ゲーム画面やチームの制作物については、公開前にチームの掲載許可・公開範囲を確認してください。

## Python作品の画像について

`assets/python-01.png` ～ `python-04.png` は、提出された `assignment04.ipynb` の説明・コード・実行結果をもとに作成した画像です。GitHub Pages公開時には同梱の `assignment04.ipynb` にリンクするようになっています。

## 調整

- 見出し、本文、各作品の説明は `index.html` の該当箇所を変更できます。
- 配色、余白、文字サイズは同ファイル冒頭の `<style>` にあります。
- 動くニューロンの線と点は末尾の `<script>` 内にあります。
- 画像の拡大表示、レスポンシブ表示に対応しています。
